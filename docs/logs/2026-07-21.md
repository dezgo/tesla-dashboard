## Gotchas discovered
- **bcrypt hash escaping:** Compose interpolates `$` in `.env`, so a bcrypt hash
  needs every `$` doubled or Caddy gets it truncated and basic auth silently
  rejects everything. Committed docs originally claimed the opposite; fixed.
- **Tesla BLE name needs *active* scanning** — passive shows the car as
  `(unnamed)` and the name match silently never fires.
- **TeslaMate doesn't work on the Fleet API for individuals (2026)** — sends
  `client_id=ownerapi`, which Fleet rejects. Owner API is the supported path.
- **HA webhook lockout collision:** `left` + `arrived` share one webhook;
  `left` fires microseconds before `arrived` on return, bumped `last_triggered`,
  and the lockout then blocked `arrived` — door never opened.
- **Don't fire the `arrived` webhook to "test"** — it operates the physical
  door. Only test with the user watching.
- **HA host died ~3am** (suspected Windows Update reboot on the media PC), not
  the Shelly script. Hardened since: Docker updated, run-on-startup on, static
  IP `.106`.
